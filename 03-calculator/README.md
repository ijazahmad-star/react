# Calculator Application

A functional calculator app built with React, demonstrating user input handling, state management, and computational logic.

## 🎯 Learning Objectives

- State management for calculations
- User input handling
- Mathematical operations implementation
- Component composition
- Event handling
- Controlled components

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Running the Project

```bash
npm run dev
```

The calculator will run on `http://localhost:5173`

## 📁 Project Structure

```
src/
├── App.jsx          # Main calculator component
├── components/      # Calculator UI components
├── util/            # Calculation utilities
└── assets/          # Images and static files
```

## 🛠️ Built With

- React 19.0.0
- Vite 4.3.9
- JavaScript (JSX)

## 📝 Key Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear and reset functionality
- Decimal number support
- Responsive button layout
- Real-time calculation display

## 💡 Concepts Covered

- State management for user input
- Event handling for button clicks
- Conditional rendering
- Component modularity
- Utility functions for calculations
